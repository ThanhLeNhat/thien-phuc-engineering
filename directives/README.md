# Directives (Layer 1)

This folder contains **Standard Operating Procedures** written in Markdown.

Each directive defines:
- **Goal** — what the task accomplishes
- **Inputs** — what data / context is needed
- **Tools / Scripts** — which execution scripts to call
- **Outputs** — expected deliverables
- **Edge Cases** — known pitfalls and how to handle them

Directives are living documents — update them whenever you discover API constraints, better approaches, common errors, or timing expectations.
